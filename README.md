## 🌟 Project Overview
Rodri & Rodriguez aims to redefine cleanliness standards. The website serves as a digital storefront that reflects the company's commitment to "Luxury Cleaning." It provides a clear value proposition, social proof through testimonials, and a streamlined conversion path via integrated contact forms.

### Brand Identity
- **Primary Palette:** Deep Emerald (`#0F3430`) and Champagne Gold (`#E4EA6B`).
- **Accent Color:** Sky Blue (`#B0E4FF`) for high-visibility Call-to-Action (CTA) buttons.
- **Typography:** Focused on readability with a weight-based hierarchy (600 for headers, 400 for body).

---

## ✨ Key Features

### 1. High-Conversion Hero Section
A dual-pane layout featuring high-quality imagery alongside a compelling CTA. The "Book Now" button utilizes a smooth 600ms transition for a premium feel.

### 2. Modern Navigation
* **Sticky Header:** Persistent navigation for easy access to site sections.
* **Mobile-First Menu:** A fully functional hamburger menu built for touch-screen accessibility.

### 3. Dynamic Testimonials
A grid-based section displaying social proof from clients like Samantha, Michael, and Luisa, reinforcing brand trust.

### 4. Why Choose Us (Value Props)
An organized, border-separated section detailing the three pillars of the company: **Quality**, **Reliability**, and **Excellence**.

### 5. Multi-Form Integration
* **Lead Generation:** A comprehensive contact form for detailed inquiries.
* **Newsletter Subscription:** A footer-integrated "Stay Connected" form to capture email leads.

## 🛠 Technologies Used

- **HTML5:** Semantic markup for SEO and accessibility.
- **Tailwind CSS v4.0:** Utilized for rapid, utility-first styling and sophisticated responsive layouts.
- **Font Awesome:** Iconography for professional visual cues.
- **JavaScript (ES6):** Custom logic for mobile menu toggling and interactive elements.
- **Google Fonts / System Fonts:** Optimized for cross-platform font rendering.
